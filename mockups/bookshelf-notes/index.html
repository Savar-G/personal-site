Bookshelf · Notes redesign

Five ways to show your notes

Same content, same stone/Geist aesthetic — five different organizing ideas. Each is fully clickable: real search, real filters, real reading. Open them side by side and see which one feels like yours.

→
A

Notes Feed

Every takeaway, quote, and note becomes a card in one filterable masonry stream, tagged by book and type. Maximum “see everything at once.”

Best if · you want to rediscover ideas across books →
B

Commonplace Book

Your notes typeset like a printed book of your own highlights — a serif reading column with a sticky index and filters. The most literary.

Best if · you want it to feel like reading, not an app →
C

Tabbed Hub

Tabs for All · Quotes · Takeaways · Notes — each shown the way it reads best, with quotes becoming a big-type wall. Search carries across tabs.

Best if · each kind of note deserves its own stage →
D

Library Table

A dense, scannable table of every book; search jumps to matches and any row expands to read its notes in place. Scales to hundreds of books.

Best if · your shelf keeps growing and you want control →
E

Book Spread

Keeps today’s shelf, adds search that flips it into cross-book results, and opens each book as a refined two-page spread with internal tabs.

Best if · you love the current book metaphor →
F

Shelf + Notes ★ what you described

The synthesis: your shelf, kept — but the covers reorganized into a responsive grid that fills the row, and clicking one opens the two-page Spread reader (E). Up top, a Shelf / Notes tab flips the same page into the Notes Feed (A) — search, type and topic filters, every note across every book.

Combines · E’s shelf & spread reader + A’s notes hub, one page, two tabs

All five reuse one shared dataset pulled from your real content/books/*.mdx files — sparse books, currently-reading, and richly-noted books all included so you can see how each layout copes. Nothing here touches your live site yet.
